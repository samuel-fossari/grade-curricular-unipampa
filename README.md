# Grade Curricular UNIPAMPA — Campus Alegrete

Acompanhe sua grade curricular de forma interativa. Marque disciplinas concluídas ou em andamento, veja quais estão disponíveis conforme seus pré-requisitos, consulte ementas e anote informações das suas aulas.

- Engenharia Agrícola
- Engenharia de Telecomunicações

## Funcionalidades

- Três estados por disciplina: não feita, em andamento e concluída
- Bloqueio automático por pré-requisitos — só aparecem disponíveis as disciplinas que você pode cursar
- Pop-up com ementa, carga horária e espaço para anotar professor, sala e horários
- Progresso salvo no navegador — sem cadastro, sem servidor
- Temas claro, escuro e alto contraste
- Ajuste de tamanho de fonte
- Funciona offline após o primeiro carregamento

## Como rodar localmente

Não precisa instalar nada. Basta clonar e abrir o arquivo:

```bash
git clone https://github.com/<seu-usuario>/grade-unipampa.git
cd grade-unipampa
```

Abra o `index.html` no navegador, ou use uma extensão de servidor local como o Live Server no VS Code.

## Aviso

Este é um projeto acadêmico independente desenvolvido por um aluno da UNIPAMPA. Não é um sistema oficial da universidade. Os dados são baseados nos PPCs públicos e podem conter imprecisões — use como referência, não como fonte definitiva.
